# Eco Automated Messages in Digital Retail using Generative AI (Thesis Project)

## Overview
This project analyzes the effect of Eco Automated Messages generated by Generative AI in digital retail websites.  
The study investigates how Perceived AI Sensitivity influences Trust, Greenwashing Suspicion, and Purchase Intention.

## Research Objectives
- Analyze the effect of message type on Trust
- Analyze the effect of message type on Greenwashing Suspicion
- Test mediation effect of Greenwashing Suspicion
- Test moderation of Perceived AI Sensitivity
- Analyze effect of Trust on Purchase Intention

## Methodology
- Quantitative experimental design (2x2 factorial design)
- Data analysis using Python
- Techniques used:
  - Reliability test (Cronbach Alpha)
  - Validity test (KMO, Bartlett, AVE)
  - ANOVA & Tukey test
  - Regression analysis
  - PROCESS Macro (mediation & moderation)

## Dataset
- Survey-based experimental data
- 2x2 design:
  - Eco vs Neutral Messages
  - High vs Low AI Sensitivity

## Tools & Libraries
Python, Pandas, NumPy, SciPy, Statsmodels, Pingouin, Factor Analyzer, PyProcessMacro
