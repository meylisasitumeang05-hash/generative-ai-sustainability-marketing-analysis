# Eco Automated Messages in Digital Retail using Generative AI (Thesis Project)

## Overview
This project analyzes the effect of Eco Automated Messages generated by Generative AI in digital retail websites.  
The study investigates how Perceived AI Sensitivity influences Trust, Greenwashing Suspicion, and Purchase Intention using a 2x2 experimental design.

The research is grounded in signaling theory within AI-driven marketing and consumer behavior context.

## Research Objectives
- Analyze the effect of message type on Trust  
- Analyze the effect of message type on Greenwashing Suspicion  
- Test the mediating effect of Greenwashing Suspicion  
- Test the moderating effect of Perceived AI Sensitivity  
- Analyze the effect of Trust on Purchase Intention  

## Methodology
- Quantitative experimental design (2x2 factorial design)
- Data analysis using Python
- Statistical techniques:
  - Reliability test (Cronbach Alpha)
  - Validity test (KMO, Bartlett, AVE)
  - Normality test and classical assumption tests
  - ANOVA & Tukey HSD test
  - Regression analysis (OLS)
  - Mediation & Moderation analysis (PROCESS Macro)

## Dataset
- Survey-based experimental dataset
- 2x2 factorial design:
  - Eco vs Neutral Messages
  - High vs Low AI Sensitivity
- Respondents: online consumers in digital retail context

## Key Variables
- Independent Variable: Type of Message  
- Moderator: Perceived AI Sensitivity  
- Mediator: Greenwashing Suspicion  
- Dependent Variables: Trust, Purchase Intention  

## Tools & Libraries
Python, Pandas, NumPy, SciPy, Statsmodels, Pingouin, Factor Analyzer, PyProcessMacro, Matplotlib, Seaborn, OpenPyXL
